# mini-shell
Este projeto tem o objetivo de desenvolver um mini interpretador de comandos que simula a execução de comandos em um terminal Linux, explorando chamadas ao sistema.

## Funcionamento
Se estiver usando Windows, utilize o WSL.

### Recompilar
Caso queira recompilar o mini shell, abra o terminal e digite:
```bash
make clean
make
```

### Compilar
Para compilar, abra o terminal e digite:
```bash
make
```

### Rodar o mini shell
Para rodar o mini shell, abra o terminal na pasta onde está o arquivo `minishell` e digite:
```bash
./minishell
```

Para sair do programa, digite `exit` ou aperte `Ctrl + C`
